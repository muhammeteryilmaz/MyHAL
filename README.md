# MyHAL

A custom Hardware Abstraction Layer (HAL) for STM32 microcontrollers.

The project uses only CMSIS and startup files. STM32 HAL drivers are 
included only because they are generated by STM32CubeIDE and are not 
used by MyHAL.

## Project Goals

- Learn STM32 at register level
- Develop a custom HAL library
- Avoid using STM32 HAL drivers
- Create reusable peripheral drivers
